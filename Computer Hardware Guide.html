Hardware Fundamentals

Computer kin cheezon se bana hai, har part kya karta hai, aur power supply ki voltage kaise check karte hain.

Unit 1 · Chapter 1

Components ki pehchan aur unka istemal

Computer kya hai?

Computer ek aisi device hai jo electronic aur electro-mechanical components se bani hoti hai. Computer khud koi kaam nahi kar sakta; jo physical hissa hota hai usay hardware kehte hain.

Ek computer system teen cheezon se milkar banta hai:

1. Hardware

Wo physical parts jinhein aap dekh, chhu aur mehsoos kar sakte hain.

Misaal: monitor, keyboard, mouse.

2. Software

Wo instructions jo computer ko batati hain ke kaam kaise karna hai.

System software operating system, compiler, editor

Application software MS-Word, Excel, accounting packages

3. People

Wo log jo computer chalate hain aur software ki instructions banate hain.

Computer ki qismein

Size, speed aur istemal ke hisab se computer systems ki teen bari qismein hain: Micro, Mini aur Mainframe.

Micro computer (PC)

Isay personal computer bhi kehte hain. Ismein ek single silicon chip par bana processor hota hai. Teen sizes mein milta hai: pocket PC, laptop PC aur desktop PC. Chhote karobar mein istemal hota hai.

Misaal: IBM compatible (IBM clone) aur Apple Macintosh.

Multiuser micro computer

Pehle micro computers sirf ek bande ke liye hote the. Ab kai micro computers ko network se jor kar kai log ek hi waqt mein istemal kar sakte hain.

Mini computer

Mainframe ka chhota version. Storage aur processing speed mainframe se kam hoti hai, aur attached printers bhi itne tez nahi hote.

Misaal: research groups, engineering firms aur colleges.

Mainframe computer

Bari aur mehngi machine jis ki processing speed bohat zyada, secondary storage bohat bari aur printers tez hote hain. Poori organization ka data process kar sakti hai.

Misaal: airline booking, railway booking, weather forecasting.

Is se hardware ki do bunyadi classes banti hain: 8-bit (PC/XT) class aur 16/32/64-bit (AT) class.

PC / XT

PC = Personal Computer. XT = eXTended PC. XT asal mein wo PC thi jis mein floppy ke saath hard disk bhi thi. In mein 8-bit processor aur 8-bit ISA bus (Industry Standard Architecture) hota tha.

AT

AT = Advanced Technology. 16-bit (baad mein 32 aur 64-bit) processors aur expansion slots wali systems. Pehli AT systems mein ISA bus ka 16-bit version tha.

Bus kya hai?

Expansion slots ko bus kehte hain. Inmein extra plug-in circuit boards lagaye jaate hain. Misalein: 16-bit ISA, 16/32-bit EISA, 32/64-bit PCI, aur 16-bit PC card (PCMCIA).

Pehchan ka asaan tareeqa

Agar system mein sirf 8-bit ISA slots hain to wo PC/XT hai (processor koi bhi ho). Agar 16-bit ya us se bare slots (ISA, EISA, PCI) hain to wo AT system hai.

System components

Motherboard

Computer ka sab se ahem hissa, kyunke baqi har cheez usi se juri hoti hai aur wahi sab kuch control karta hai. Ye alag alag shapes mein milta hai. Is mein ye hote hain: processor slot, voltage regulators, chipset, level 2 cache, memory (SIMM/DIMM) sockets, bus slots, ROM BIOS, clock/CMOS battery aur Super I/O chips.

Processor (CPU)

Computer ka "engine". Ye memory se commands parhta hai aur unhein execute karta hai. Computer ke sab se mehnge parts mein se hai, magar sab se chhote parts mein bhi.

Misaal: Intel Pentium 4.

Primary memory (RAM / ROM)

Memory programs aur data ko execution ke dauran sambhalti hai. RAM (Random Access Memory) wo sab programs aur data rakhti hai jo processor abhi istemal kar raha ho. RAM volatile hai: bijli band hote hi data mit jaata hai.

ROM (Read Only Memory) permanent hai: bijli band hone par bhi data nahi mitta. Aam tor par is se operating system load kiya jaata hai.

Hard disk drive

Aluminium ya ceramic ki ghoomti hui platters jin par magnetic media ki coating hoti hai. Isay secondary memory bhi kehte hain. Jo programs RAM mein nahi rakhe ja sakte, aur system band hone par bhi data mehfooz rakhna ho, wo yahan save hota hai. Capacity platters ki density, size aur tadaad par depend karti hai.

CD-ROM drive

CD-ROM = Compact Disk Read Only Memory. Gramophone records jaisi chhoti disks jin mein digital information hoti hai. Naam ke mutabiq ye read only medium hai, magar ab writable CDs bhi aati hain.

Floppy disk drive

Secondary storage ka sab se slow aur sab se chhota tareeqa. Files ek computer se doosre tak le jaane aur chhoti files ka backup lene ke kaam aata hai. Pichle 10 saal ke PCs mein standard 3½ inch, 1.44 MB floppy drive hoti hai.

Keyboard

Zyadatar computers ka main input device. Isse text aur commands likhe jaate hain. Aaj kal multimedia aur wireless keyboards bhi hain.

Mouse

Graphical User Interface ke saath mouse ek ahem input device bana. User bas point aur click karta hai. Mouse ka sab se bara faida aasani hai: kai kaam keyboard se mouse se zyada aasan ho jaate hain.

Monitor

Television jaisi khaas high-resolution screen. Video card apni video memory ka content monitor ko 1 second mein 60 ya zyada baar bhejta hai. Screen red, green aur blue dots se bani hoti hai jinhein peeche se electron beam roshan karti hai. Video card ki DAC chip tay karti hai kaun sa dot kitni roshni se jale, aur isi se tasveer banti hai.

Cabinet

Wo dabba jis mein computer ke zyadatar parts rehte hain. Ye parts ko hifazat deta hai, hawa ka rukh (cooling airflow) tay karta hai, aur parts lagane aur nikalne ki jagah deta hai. Cabinet ka design motherboard ki shape ke mutabiq hona chahiye.

Power supply (SMPS)

SMPS = Switch Mode Power Supply. Ye PC ke har part ko bijli deta hai. Is ka asal kaam 230 V AC ko system ke liye zaroori 3.3 V, 5 V aur 12 V DC mein badalna hai.

Bijli dene ke ilawa ye yeh bhi yaqeeni banata hai ke system tab tak na chale jab tak bijli kafi na ho. Start se pehle power supply andar ki checking karta hai. Agar sab theek ho to motherboard ko ek khaas signal Power_Good bhejta hai. Agar ye signal musalsal na mile to computer chalta hi nahi.

Misaal

Bijli ka voltage gir jaye (AC voltage dip) aur power supply par zor parh jaye ya wo garam ho jaye, to Power_Good signal gir jata hai. Nateeja: system reset ho jata hai ya poori tarah band ho jata hai.

Peripheral devices

Koi bhi external device jo computer ke bunyadi kaam ke liye zaroori nahi, magar extra salahiyat deti hai, peripheral kehlati hai.

Misaal: printers, modems, speakers.

Modem

Modulator + Demodulator. Ye phone line par digital data bhejne ke kaam aata hai. Bhejne wala modem digital data ko analog mein badalta hai (taa ke phone line se guzar sake), aur wasool karne wala modem usay wapas digital banata hai. Internet se connect hone ke liye istemal hota hai.

Computer → modem → telephone network → modem → terminal.

Mukhtalif levels par voltage napna

Multimeter kya hai?

Meter napne wala instrument hai. Ammeter current napta hai, voltmeter do points ke darmiyan potential difference (voltage) napta hai, aur ohmmeter resistance napta hai. Multimeter in sab kaamon ko (aur kuch aur ko) ek hi instrument mein jama kar deta hai.

Multimeter se voltage signals check hote hain, power supply ka output test hota hai, aur kisi circuit ya cable mein continuity (taar toota to nahi) bhi dekhi jaati hai.

Digital Multimeter (DMM)

Power supply par sab se aasan test uske output voltages check karna hai. Is se pata chalta hai ke power supply theek chal raha hai aur voltages sahi tolerance range mein hain ya nahi.

Yaad rakhein

Voltages hamesha power supply ko load ke saath napein, yaani jab wo system mein lagi ho aur system on ho.

Back probing

Chalte system ki voltage napne ke liye connectors par back probing karte hain. Power supply se nikalne wali taarein: red, yellow, orange, black aur white. Zyadatar connectors ke peeche taar andar jaane wali jagah khuli hoti hai. Meter ki leads itni patli hoti hain ke taar ke bagal se andar ja kar metal terminal ko chhu leti hain. Chunke aap connector ko peeche se probe karte hain, isay back probing kehte hain.

Power_Good signal check karna

Power_Good pin par +3 V se +6 V ka voltage hona chahiye. Agar reading is range mein nahi to system ko Power_Good signal nahi milta aur wo theek se start nahi hota. Aksar is ka matlab hota hai ke power supply kharab hai aur badalni hogi.

Testing ke liye desired voltage se 10% tak farq qabil-e-qabool hai. Behtar power supplies mein 5% tight tolerance hoti hai. ATX power supplies ke liye voltage rating ke 5% ke andar honi chahiye, siwaye 3.3 V ke jis ke liye 4% hai.

Rail aur tolerance chunein, phir meter ki reading likhein. Range upar wali table se li gayi hai.

Meters: leads aur scale

DMM ke paas test leads (probes) ki ek jori hoti hai. Meter ki setting ke mutabiq ye electrical resistance, direct current (DC) voltage ya alternating current (AC) voltage napti hai.

DC voltage aam tor par kai scales mein parhi ja sakti hai, maximum 200 mV, 2 V, 20 V, 200 V aur 1000 V tak. Computers +5 V aur +12 V istemal karte hain, is liye napne ke liye 20 V scale chunni chahiye.

Ehtiyat

200 mV ya 2 V scale par napne se meter kharab ho sakta hai, kyunke voltage us se bohat zyada hoti hai. 200 V ya 1000 V scale par kaam to hota hai, lekin 5 V aur 12 V maximum scale ke muqable mein itni chhoti hoti hain ke reading ki accuracy kam ho jati hai. Agar voltage ka andaza na ho to sab se upar wale scale se shuru karein aur neeche aayein.

Multimeter se voltage napne ke steps

A. Wall socket ki 230 V check karna
  1. Multimeter ka knob ghuma kar kisi bhi AC voltage par set karein jo 230 V se zyada ho.
  2. Positive lead (red) ko phase (+ve terminal) mein aur negative lead (black) ko neutral (-ve terminal) mein lagayein.
  3. Reading note karein. Honi 230 V chahiye, magar amli tor par 210 se 230 V tak theek hai.
B. Hard disk ki power check karna
  1. Multimeter ko DC voltage par set karein, 12 V se zyada aur zyada se zyada 20 V.
  2. System on karein.
  3. Red lead ko power connector ki red taar mein aur black lead ko hard disk power connector ki black taar mein lagayein.
  4. Reading +5 V honi chahiye. Tolerance upar wali tables se dekhein.
  5. Yahi kaam yellow aur black taaron ke liye bhi dohrayein.

Isi tareeqe se motherboard, CPU fan, floppy drive, CD-ROM wagairah ki power bhi napi ja sakti hai.

Khulasa
  1. Computer ki power supply napne ke liye digital multimeter istemal hota hai.
  2. System start hone ke liye Power_Good signal zaroori hai.

Motherboard

Motherboard kya hai?

Motherboard kisi bhi personal computer ka sab se ahem component hai. Is mein computer ke lagbhag tamam zaroori hisse hote hain. IBM ise "system board" ya "planar board" kehta hai aur kuch aur manufacturers "logic board".

Ye PC ke andar ka main circuit board hai jis par processor, memory aur expansion slots lage hote hain aur jo seedha ya ulta har part se juda hota hai. Ye ek chipset ("glue logic"), ROM mein kuch code, aur mukhtalif interconnections ya buses se bana hota hai.

Motherboard ka irtiqa (Evolution)

Asal PC mein bohat kam integrated devices thin: sirf keyboard aur cassette deck (storage) ke ports. Baqi sab kuch, display adapter, floppy aur hard disk controllers samet, add-in cards ke tor par expansion slots se jora jaata tha.

Waqt ke saath zyada devices motherboard mein integrate hoti gayin. Magar graphics, networking, SCSI aur sound aksar alag hi rahe.

Integration ke faide

Cost kam hoti hai, jagah bachti hai, aur sound ya graphics card alag se khareedne ki zarurat nahi parti.

Integration ke nuqsanat

Upgrade mushkil, kharab ek part ke liye poora motherboard badalna parta hai, aur kai integrated boards ko non-standard cases chahiye hote hain.

Misaal

Jin parts ki specification sab se tezi se badalti hai, yaani RAM, CPU aur graphics, wo sockets ya slots mein hi rakhe jaate hain taa ke aasani se badle ja saken. Jo cheezein sab ko nahi chahiye (networking, SCSI) wo base specification se bahar rakhi jaati hain taa ke cost kam rahe.

Motherboard form factors

Form factor ka matlab board ka physical size aur dimensions. Ye tay karta hai ke motherboard kis qism ke case mein fit hoga. Shuru ke PCs mein 12 inch chora AT form factor tha. Is ki bari size se upgrade mushkil tha, is liye 1989 mein chhota Baby-AT aaya. Sab designs open standards hain, is liye manufacturers ke boards mein design ka kafi farq ho sakta hai.

Expansion slots

Ye motherboard par computer ke peeche ki taraf lagi lambi patli connectors hoti hain. Inmein mukhtalif expansion cards lagti hain: display card, hard drive controller, sound card, network card, modem card wagairah. Card lagane par wo motherboard ke data, address aur control bus se jur jaata hai.

Bus kya hai?

Bus ek electronic raasta hai jis par signals computer ke ek hisse se doosre tak jaate hain. Buses ki qismein is par hain ke wo ek waqt mein kitne bits bhej sakti hain.

  • Agar data bus 8 bit chora hai to wo ek waqt mein 8 bits bhejta hai (8-bit bus).
  • 8-bit bus par 16-bit data bhejne ke liye do transfers lagte hain.
  • Bandwidth = ek waqt mein bus mein kitna data fit ho sakta hai.
Misaal: paani ka paip

Jaise paip se zyada paani nikalne ke liye aap ya to paip ka diameter bara kar sakte hain ya paani ka bahao tez kar sakte hain. Isi tarah bus ki width badha kar (8 bit se 16 bit) ya bandwidth badha kar (8 MHz se 20 MHz) data ka bahao badhaya jaata hai.

CPU (Main processor)

Motherboard ka sab se ahem hissa. Ye system ke tamam andruni kaam control karta hai aur har PC ka dimagh hai. Aam tor par ye socket mein lagaya jaata hai, solder nahi hota, is liye kharabi par badalna aasan hai.

Misaal: Intel 8088, 8086, 80286, 80386, 80486, Pentium, Pentium MMX, Pentium-II, Pentium III, Pentium-IV.

Coprocessor

Special purpose microprocessor jo main processor ke kuch kaam apne zimme le kar usay tez karta hai. Sab se aam math coprocessor hai jo mathematical calculations mein madad karta hai. Purane systems (XT, AT, AT-386) mein ise motherboard ke special socket mein lagana parta tha, jabke aaj ke CPUs mein math coprocessor andar hi built-in hota hai.

Memory

Memory wo jagah hai jahan computer program (instructions ka set) aur data rakhta hai.

Misaal

Marks sheet print karne wale program ko data chahiye: students ke roll number, naam aur mukhtalif subjects ke marks.

RAM

Read/write memory. Processor isay program, data aur beech ke nateeje rakhne ke liye istemal karta hai. Volatile hai: bijli band to data ghayab. Motherboard par lagne ke tareeqe:

ROM

Naam ke mutabiq read only; data manufacturer likhta hai. Bara faida: non-volatile, bijli band hone par bhi data rehta hai. Motherboard par ek ya zyada ROM chips hoti hain. XT ke liye 64 KB kafi tha, AT ko 256 KB chahiye.

Memory ki ikaaiyan
Tool: Memory unit converter

Bit = 0 ya 1. Nibble = 4 bits. Byte = 8 bits. 1 KB = 1024 bytes. 1 MB = 1024 KB. 1 GB = 1024 MB.

BIOS

BIOS = Basic Input Output System ("bye-os" parha jaata hai). Ye ROM mein rakhe sab se ahem programs mein se ek hai. Is ki wajah se aap ke application programs aur hardware (floppy, hard disk, video adapter wagairah) aapas mein baat kar sakte hain. Is mein POST (Power-On-Self-Test) bhi hota hai jo system on hote hi motherboard aur juri hui devices check karta hai.

Asal BIOS IBM ne banaya tha, magar ab compatible BIOS Award, Phoenix aur American Megatrends Inc. (AMI) jaise manufacturers bhi banate hain.

CMOS memory

CMOS = Complementary Metal Oxide Semiconductor. Purane IBM XT mein BIOS jumpers ki madad se jaanta tha ke kaun se components lage hain. IBM AT aur us se upar ke systems mein jumpers nahi hote; wo system ki configuration, tareekh aur waqt wagairah CMOS memory mein rakhte hain. Ye memory ek battery se chalti hai, is liye system band hone par bhi information mehfooz rehti hai. Boot par BIOS CMOS ki information ko lage hue components se milata hai aur farq milne par error message dikhata hai.

Cache memory

Thori si (aam tor par 1 MB se kam) tez raftaar memory jo CPU ke andar ya bilkul qareeb hoti hai. Ye processor ko sab se zyada manga jaane wala data aur instructions deti hai.

Level 1 (primary) processor ke sab se qareeb. Level 2 (secondary) doosre number par qareeb, aam tor par motherboard par.

Support chips / Chipsets

Processor aur memory ke ilawa motherboard par bohat si controller chips hoti hain jo sab ko jorti hain. Ek zamane mein interrupt controller, DMA controller, timer, clock chip, bus controller aur I/O interface chips ka alag alag hona zaroori tha. Ab VLSIC (Very Large Scale Integrated Circuits) ki badaulat 2-3 chips wo sab kaam kar leti hain jo pehle darjanon chips karti thin. In VLSIC chips ke set ko chipset kehte hain. Kai chipsets mein serial/parallel ports, floppy aur hard disk controller, USB, LAN, audio aur display adapter bhi shamil hote hain.

Motherboard configuration
  • PC aur XT class ke zyadatar motherboards jumpers ya switches se set hote hain.
  • AT aur baad ki machines mein options CMOS RAM mein rakhe jaate hain aur BIOS ROM ki SETUP utility se set hote hain.
Ehtiyat

Motherboard ki configuration hamesha bilkul theek honi chahiye. Ghalat setup se system kharab kaam kar sakta hai ya crash ho sakta hai.

Motherboard ka model kaise pata karein?

Aakhri ISA slot ke side par laga safed sticker dekhein, ya board par chhape hue nishanat parhein.

  2. Is mein CPU, memory, SMPS connector jaise ahem components hote hain.
  3. Integrated motherboards mein graphics, LAN, audio wagairah board ke andar hi hote hain (sasta hal).
  4. Form factors: Baby-AT, ATX, NLX, LPX.
  5. Motherboard ka model: aakhri ISA slot ke side wala safed sticker ya board par chhapa hua.
Unit 2 · Chapter 2

Ports

Introduction

Kisi bhi PC system mein sab se bunyadi communication ports serial aur parallel ports hain. Serial ports shuru mein un devices ke liye the jo system se do-tarfa (bi-directional) baat karti hain, jaise modems, mice aur scanners. Naye parallel port standards ab parallel port se bhi tez do-tarfa communication ki ijazat dete hain.

Serial ports

Serial port computer ke sab se bunyadi external connections mein se hai aur 20 saal se zyada se zyadatar computers ka hissa raha hai. Naye systems USB ko tarjeeh dete hain, magar zyadatar modems, kuch printers, PDAs aur digital cameras ab bhi serial port istemal karte hain. Aksar computers mein do se zyada serial ports nahi hote.

Naam "serial" is liye hai ke ye data ko serialize karta hai: ek byte lekar uske 8 bits ek ke baad ek bhejta hai.

Faida

Sirf ek taar chahiye 8 bits bhejne ke liye (parallel ko 8 taarein). Cable sasti aur patli.

Nuqsan

Data bhejne mein parallel se 8 guna zyada waqt lagta hai.

Tool: Serial vs Parallel

Ek byte (8 bits) ka safar. Dekhein parallel mein saare bits ek saath jaate hain, serial mein qatar mein.

Parallel port: 8 taarein, poora byte ek hi waqt mein pahunchta hai
Serial port: 1 taar, 8 bits ek ke baad ek, is liye zyada waqt
Start bit, stop bit, parity

Har byte se pehle serial port ek start bit (value 0) bhejta hai. Har byte ke baad ek stop bit bhejta hai jo batata hai ke byte mukammal hua. Ek parity bit bhi ja sakta hai.

Serial ports ko communication (COM) ports bhi kehte hain aur ye bi-directional hote hain.

Half-duplex

Data bhejne aur wasool karne ke liye wohi pins istemal hon to ek waqt mein sirf ek taraf data ja sakta hai.

Full-duplex

Alag alag pins hon to data dono taraf ek hi waqt mein ja sakta hai.

UART kyun zaroori hai?

Serial ports ko theek se chalne ke liye ek khaas controller chip chahiye: UART (Universal Asynchronous Receiver/Transmitter). UART computer ke system bus ka parallel output le kar usay serial form mein badalta hai. Tez chalne ke liye zyadatar UART chips mein 16 se 64 KB ka buffer hota hai jo system bus se aane wala data cache karta hai jab tak wo serial port se bahar ja raha ho. Misaal: National Semiconductor NS16550D UART chip (40-pin DIP).

Aam serial ports ki maximum speed 115 Kbps hoti hai. ESP (Enhanced Serial Port) aur Super ESP 460 Kbps tak ja sakte hain.

Parallel port ki buniyad

Parallel ports IBM ne PC ko printer se jorne ke liye banaye. IBM chahta tha ke uska PC us waqt ke bare printer maker Centronics ke printers ke saath chale, magar usne PC par wohi port interface istemal na karne ka faisla kiya. IBM engineers ne 25-pin DB-25 connector ko 36-pin Centronics connector se jor kar ek khaas cable banayi. Doosre printer makers ne bhi Centronics interface apna liya aur ye ajeeb hybrid cable de facto standard ban gayi.

Jab PC parallel port se data bhejta hai to ek waqt mein 8 bits (1 byte) bhejta hai. Standard parallel port 1 second mein 50 se 100 KB data bhej sakta hai.

SPP, EPP aur ECP

Parallel port ki asal specification unidirectional thi: har pin par data sirf ek taraf jaata tha. 1987 mein PS/2 ke saath IBM ne bidirectional design diya jo SPP (Standard Parallel Port) kehlata hai aur ab pehle design ki jagah le chuka hai. EPP: Enhanced Parallel Port

1991 mein Intel, Xircom aur Zenith ne banaya. 500 KB se 2 MB per second data. Printers ke bajaye non-printer devices (khaas tor par storage) ke liye jinhein sab se zyada transfer rate chahiye.

ECP: Extended Capabilities Port

1992 mein Microsoft aur Hewlett Packard ne mil kar elan kiya. Ye printers ki speed aur functionality behtar karne ke liye bana.

1994 mein IEEE 1284 standard aaya jis mein EPP aur ECP dono shamil thay. Kaam karne ke liye operating system aur device dono ko required specification support karni chahiye. Aaj zyadatar computers SPP, ECP aur EPP support karte hain aur khud pehchan lete hain. Haath se mode select karna ho to zyadatar computers mein BIOS se kiya ja sakta hai.

USB kya hai?

USB = Universal Serial Bus. Pehle devices jorna ek bara dard-e-sar tha: printers parallel port par (aur aksar computer mein sirf ek hota), Zip drives jaisi tez devices ko bhi wohi port, modem aur kuch printers serial port par (jo bohat slow), aur tez devices ke liye apne cards jo case ke andar slot mein lagte (slots limited aur software install karna mushkil).

USB ka maqsad in sab pareshaniyon ko khatam karna hai. Ye ek ikhatta, standard aur aasan tareeqa deta hai ke aap computer se 127 devices tak jor saken. Aaj lagbhag har peripheral USB version mein milta hai.

USB devices ki misalein: PrintersScannersMiceJoysticksFlight yokesDigital camerasWebcamsScientific data acquisition devicesModemsSpeakersTelephonesVideo phonesStorage (Zip drives)Network connections

USB kaise kaam karta hai

Aaj kal har computer ke peeche ek ya zyada USB connectors hote hain. Operating system bhi USB ko support karta hai, is liye device drivers ka install karna bhi tez aur aasan hai. Kisi USB device ko jorna bas us ka connector computer ke peeche USB port mein laga dena hai.

  • Agar device naya hai to operating system khud pehchan leta hai aur driver disk maangta hai.
  • Agar pehle install ho chuka hai to computer usay active kar ke baat shuru kar deta hai.
  • USB devices kisi bhi waqt jori aur hatai ja sakti hain.
"A" connector

Computer ki taraf, yaani upstream. Kai devices ki cable mein ye pehle se lagi hoti hai.

"B" connector

Alag alag devices ki taraf, yaani downstream. Agar device mein cable nahi hai to usmein "B" socket hota hai.

Upstream aur downstream par alag connectors hone ki wajah se ghalti ka imkan hi nahi: cable ka "B" connector device mein laga dein to kaam karega, aur kisi bhi "A" connector ko kisi bhi "A" socket mein laga dein to kaam karega.

Khulasa
  1. PC par ports ki mukhya qismein: Serial, Parallel aur USB.
  2. Serial port se mouse, modem wagairah jurte hain.
  3. Parallel port se printers jurte hain.
  4. USB se webcam, video phones, scanners wagairah jurte hain.

Introduction

Purane PCs ka masla

Kuch purane PCs naye hardware ke saath kaam nahi karte kyunke unke BIOS mein us hardware ki support nahi hoti. Hal: BIOS ko naye BIOS se badal dein, ya us hardware ka device driver install karein.

Bootstrap loader

Definition: Wo routine jo operating system dhoondti hai aur usay load ya "boot" karti hai. Agar OS mil jaye to usay load kar ke computer ka control de deti hai.

Is program mein operating system ki poori functionality nahi hoti, magar ye khaas is liye banaya jaata hai ke OS ko start karne ke liye kaafi software load kar sake. Aksar kai marahil wale boot loaders hote hain, jin mein chhote programs ek doosre ko bulate hain, aakhri program OS load karta hai. Naam "bootstrap" is muhavre se hai ke koi apne hi jute ke fite pakar kar khud ko uthaye.

  • IBM PC aur compatibles par pehla stage boot loader hamesha 512 bytes ka hota hai aur AA55h value par khatam hota hai (BIOS ye value dekh kar yaqeen karta hai ke ye sahi boot loader hai).
  • Second-stage boot loader aam tor par khud operating system nahi hota; misalein: NTLDR, LILO, GRUB. Ye OS load karta hai aur control us ko de deta hai.

Booting

Booting wo bootstrapping process hai jo user ke computer on karne par operating system shuru karta hai. Boot sequence un amal ka silsila hai jo computer on hone par OS load karne ke liye karta hai.

Tool: Boot sequence (har step par click karein)
Aam PC taqreeban 1 minute mein boot hota hai (is mein se lagbhag 15 second shuruati boot loaders aur baqi OS load karne wale loader ke).

Network boot mein (jahan machine diskless ho sakti hai) sequence wohi hota hai, magar BIOS network card ke ROM mein hota hai aur network se boot loader laata hai. Boot process tab mukammal samjha jaata hai jab computer user se interact karne ya aam applications chalane ke qabil ho jaye.

Misaal

Bare servers ko saari services start karne mein kai minute lag sakte hain, is liye wo kuch services pehle aur kuch baad mein start karte hain. Embedded systems (jaise TV) ko lagbhag foran boot hona parta hai, is liye unka poora OS ROM ya flash memory mein hota hai.

Khulasa
  1. BIOS = Basic Input Output System.
  2. BIOS ke chaar components hain.
  3. Computer ke start hone ke marahil ko booting sequence kehte hain.
  4. Bootstrap loader wo program hai jo OS ka kuch hissa hard disk se kheench laata hai.
  5. Bootstrap loader multistage hota hai.
  6. BIOS mein low-level routines hote hain jo seedha hardware se baat karte hain.

Unit 5 · Chapter 1

Viruses

Virus kya hai?

Virus bhi ek computer program hi hai. Dusre programs ki tarah ismein bhi instructions hoti hain. Magar application ke bar aks, virus aam tor par computer ko wo kaam karne ko kehta hai jo aap nahi chahte, aur wo khud ko aap ke aur dusron ke computers mein phaila sakta hai.

Virus ek nuqsandeh software hai jis ki ye khasiyat hoti hain:

Hidden (chhupa hua)

Aam DIR command se nazar nahi aata.

Self-replicating

Khud ba khud apni copy banata hai aur dusri files aur disks ko infect karta hai.

Delayed action

Aap ko kafi der baad pata chalta hai ke virus lag chuka hai, hatta ke aap ke backups bhi infected ho sakte hain.

Virus kitna khatarnak?

Ye open networks (jaise Internet) par bohat tezi se phailte hain aur kam waqt mein arbon dollar ka nuqsan karte hain. Sab se kam nuqsan wala virus bhi jaan lewa ho sakta hai. Misaal: aspatal ke life-support system mein aisa virus jo computer ko roke aur message dikhaye jab tak koi key na dabaye, jaan lewa ban sakta hai. Virus banane wale bhi use phailne se rok nahi sakte, is liye users ko "virus-aware" hona zaroori hai.

Virus ke dakhil hone ke aam raaste

Pehla sawal ye hai: virus computer mein kaise ghusta hai? Agar aap ko jawab pata ho to in raaston ki hifazat kar ke infection se bach sakte hain.

Removable disk drives

Floppy, CD, USB jaise drives.

Computer networks

Network se jure computers.

Internet

E-mailWeb pagesFile Transfers (FTP)DownloadsNewsgroups

Viruses ki qismein

Worms

Dusre viruses se alag: ye files ko infect nahi karte. In ka sirf maqsad zyada se zyada tezi se doosre systems tak phailna hai. E-mails, computer networks aur Internet IRC channels ke zariye replicate hote hain, aur PC ki memory ke andar bhi.

Trojan horses

Asal mein virus nahi kehe ja sakte. Naam Yunani (Greek) kahani se hai jahan lakri ke ghode mein chhup kar sipahi Troy shehar mein dakhil hue. Trojans bhi bezarar nazar aane wale programs hote hain jo kisi bhi raaste se computer mein aate hain. Jab chalte hain (naam aur khasiyat user ko dhoka dene wali) to dusre nuqsandeh programs install kar dete hain.

Logic bombs

Tab hi system ko nuqsan pahunchate hain jab ek ya zyada shartein pooree hon. Replicate nahi hote, is liye virus nahi mane jaate; ye user ke actions (aksar anjaane mein copy ya execute karna) par depend karte hain.

Misaal: "agar tareekh falan din ho jaye to files mita do."

Encrypted

Ye virus ki category nahi balkay ek technique hai. Koi bhi virus encrypted ho sakta hai. Virus khud ko encode/encrypt kar leta hai taa ke antivirus usay aasani se na pakar sake. Kaam karne ke liye khud ko decrypt karta hai aur kaam khatam hote hi dobara encrypt kar leta hai.

Polymorphic

Aise viruses jo antivirus se bachne ke liye nayi technique istemal karte hain (aksar sab se mushkil se pakre jaate hain). Har infection ke saath badal jaate hain, is tarah apni bohat si alag shakal ki copies bana lete hain.

Virus ki alamaat (Symptoms)

Aisa lag sakta hai ke aap ke computer mein virus hai, magar pakka tab pata chalta hai jab antivirus tool (jo viruses dhoondte aur khatam karte hain) usay pakre. Kuch alamaat itni wazeh hotee hain ke pehchani ja sakti hain:

Screen par ajeeb messagesComputer ka slow honaFiles ki properties ya size badalnaFiles/folders ghayab honaComputer start na honaInfected disk ka content kho jana

Virus kya infect karte hain?

Viruses ke bare targets storage devices (hard aur floppy disks) par maujood files hain. Ye program files ko nishana banate hain. Program asal mein ek aisi file hai jis ka extension EXE ya COM hota hai.

  • Aise viruses bhi hain jo non-program files ko infect karte hain. In documents mein macros hote hain, yaani chhote programs jo user kuch file types mein shamil kar sakta hai.
  • Storage devices khud bhi nishane par hote hain, khaas tor par boot sector. Jahan files rakhi jaati hain us jagah par hamla karne se un mein maujood saari information mutassir hoti hai.

Antivirus software ka aghaaz

  • Virus experts ne 40,000 se zyada viruses aur unki qismein record ki hain, magar sirf taqreeban 200 hi aam taur par phail rahe hote hain (kitab ke mutabiq). Zyadatar viruses sirf waqt zaaya karne wale hote hain; nuqsan karne wale (destructive payload) asal khatra hain.
  • Viruses 1960s ki shuruat se hain, yaani computers ke aaghaz se, lekin 1980s tak ye zyadatar lab ke namoone the, jo researchers ne control mahaul mein chhode.
  • 1980s mein jab pehli baar bahar aaye to "sneaker net" (floppy disks ko log hath se le jaa kar computers mein lagate the) ke zariye aahista phailte the. Internet aur e-mail ne unka phailna tez kar diya.
  • Kitab ke mutabiq, e-mail se phailne wale viruses (jaise MelissaLoveLetter) ne aam user ke virus se takrane ka imkan bohat barha diya. E-mail viruses 81 percent infections ke zimmedar thay aur kuch hi minutes mein hazaron machines infect kar sakte thay.

Virus se bachne ke 9 tareeqe

  1. Kisi anjaan, shak wale ya na-qabil-e-aitbar source ki e-mail ke attachments na kholein.
  2. Jab tak pata na ho ke attachment kya hai, na kholein, chahe dost ki taraf se hi kyun na lage. Kuch viruses khud ko e-mail se phaila lete hain. Behtar hai ke us se pooch kar confirm karein ke us ne wakai bheja.
  3. Agar subject line mushkook ya ghair mutawaqqe ho to attachment na kholein. Kholna zaroori ho to pehle file ko hard drive mein save karein (aur scan karein).
  4. Chain emails aur junk (spam) emails delete kar dein. Un ka jawab na dein, aage forward na karein. Ye network ko jam karti hain.
  5. Ajnabiyon se files download na karein.
  6. Internet se files download karte waqt ehtiyat karein. Source mustanad ho aur download site par antivirus ne files check ki hon. Shak ho to download na karein, ya floppy par download kar ke apne antivirus se test karein.
  7. Antivirus software ko baqaaida update karte rahein. Har mahine 500 se zyada viruses dariyaft hote hain. Kam az kam virus signature files update hone chahiye; kabhi kabhi scanning engine bhi.
  8. Apni files ka regular backup lein, aur backup copy aisi jagah rakhein jo aap ki kaam ki files se alag ho, behtar hai computer par na ho.
  9. Shak ho to kholein, download karein ya chalayein nahi. Na chalana sab se ahem ehtiyat hai. Apne OS, web browser aur email ke updates ke liye vendors se rabta karte rahein (misaal: Microsoft ka security section).
Khulasa
  1. Virus ek self-replicating code hai jo bohat nuqsan kar sakta hai.
  2. Qismein: worms, Trojans, logic bombs, encrypted aur polymorphic.
  3. Alamaat: file size mein tabdeeli, system slow hona, files ghayab hona, system start na hona.
  4. Dakhil hone ke aam raaste: infected floppies, Internet, Compact Disks.
  5. Viruses aam tor par storage devices aur un par maujood files ko infect karte hain.

Antivirus patches ke zariye system ki recovery

Patches ke automatic updates

Antivirus programs ke naye versions mein automatic update ki sahulat hoti hai. Isay istemal karne ke liye Internet se connect hon, antivirus chalayein aur Update button dabayein. Process bilkul khud-kaar hai. Kuch programs mein button dabane ki bhi zarurat nahi: Internet se jurte hi khud update ho jaate hain.

Phir bhi check karein

Chahe program automatic update par ho, ye zaroor check karein ke update wakai ho raha hai. Kam az kam hafte mein ek baar antivirus kholein aur dekhein ke aakhri update ki tareekh bilkul taaza hai. Jab virus activity bohat zyada ho to automatic ke saath saath manual update bhi kar lein.

Update schedule karna (Norton)
  1. System Tray mein Norton AntiVirus Corporate Edition ke peele shield icon par double-click karein.
  2. Norton AntiVirus window mein File phir Schedule Updates... par click karein.
  3. Schedule Virus Definition Updates window mein Schedule button dabayein.
  4. When hisse mein din aur waqt chunein jab aap ka computer on aur Internet se juda hona chahiye (misaal: Weekly, Every Wednesday, 11:00 AM), phir OK.
  5. Dobara Schedule Virus Definition Updates window aaye to OK kar ke tabdeeli save karein.
  6. Norton AntiVirus program se bahar nikal jayein.

Manually download karna

Agar automatic update ki sahulat nahi hai, ya theek se kaam nahi kar rahi (aisa hota bhi hai!), to aap ko manufacturer ki website se virus updates download karne parenge.

  • Norton AntiVirus users: www.symantec.com
  • McAfee VirusScan users: www.mcafee.com

Apne operating system ke liye sab se naya update dhoondein aur apne computer par download karein. Agar Open ya Save ka ikhtiyar mile to Open chunein, file khud install ho jayegi. Agar Save kiya hai to file dhoondh kar us par double-click kar ke installation mukammal karni hogi.

Viruses ke liye scan karna

  1. Start button par click kar ke Programs mein jayein, ya Desktop par Norton antivirus ke icon par, ya status bar ke Norton antivirus icon par click karein.
  2. Maujood options mein se apni zarurat ka chunein. Misaal: floppy scan karni ho to floppy option, C drive scan karni ho to C drive chunein.
  3. Ye scan karta hai aur agar infected files hon to kai options ke saath report karta hai.
  4. Options: 1) Clean (virus saaf karna). 2) Agar saaf na ho sake to Quarantine ya Delete karne ko kahega.
  5. Ab wo waqt hai jab aap ko vendor ki site se patches download kar ke install karne hain. Phir system ko dobara scan karein taa ke wo virus saaf ho jo pichli koshish mein saaf nahi hua tha.
  6. Agar ye bhi virus saaf karne mein madadgar na ho to behtar hai ke vendor ko report karein.
Khulasa
  1. Patches manually ya automatically update kiye ja sakte hain.
  2. PC ko infection se bachane ke liye viruses ke scheduled scan zaroor apnayein.
